TypeTwice

Type one short sentence before a site opens, and decide whether you still want to go in.

General

sec
min

The unlock time is not a strict viewing limit. When it runs out, TypeTwice does not interrupt the page you are reading. It asks again the next time you come back to the tab, reload it, or move to another page on that site. Changes apply to new challenges; a sentence already on screen keeps its own times.

Sites

TypeTwice asks for access to a site only when you turn it on, and gives the access back when you turn the site off or remove it. A site and all of its subdomains share one unlock.

    Sentences

    Use a UTF-8 text file with one English sentence per line. Blank lines are skipped and duplicates are removed. Curly quotes, dashes, the ellipsis and special spaces are converted to plain ASCII; any other character outside printable ASCII rejects the whole file, so nothing is imported by halves.

    TypeTwice keeps its own copy of the imported sentences. It does not watch the original file, so import it again after you edit it.

    How it works

    • Everything is stored in this browser. There is no account and nothing is sent to a server.
    • Unlocks live only for the browser session. Restarting the browser or reloading or updating the extension clears them, and the next visit asks for a new sentence.
    • The gate is a speed bump, not a blocker. It covers the page but does not stop the site from loading, and sound or video behind it may keep playing.
